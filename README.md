project name: exam proctoring audit log system
group details: Sunday group 1
team member: Khaled Yasser el-Sayed abdullah
project description: The Exam Proctoring Audit Log System is designed to securely monitor online examinations and maintain a comprehensive, tamper-evident audit trail of all student activities. The system efficiently tracks events such as tab-switching, navigation, and system interactions during exams to ensure academic integrity and provide reliable reports for institutional review.
