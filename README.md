اسم المشروع: exam proctoring audit log system
مجموعه: مجموعه 1 يوم الاحد
اسماء الطلبه: خالد ياسر السيد عبدالله الجنايني
الوصف: 
The Exam Proctoring Audit Log System is designed to securely monitor online examinations and maintain a comprehensive, tamper-evident audit trail of all student activities. The system efficiently tracks events such as tab-switching, navigation, and system interactions during exams to ensure academic integrity and provide reliable reports for institutional review.
يهدف نظام مراقبة الامتحانات وتسجيل تدقيق الأحداث (Exam Proctoring Audit Log System) إلى مراقبة الامتحانات التي يتم إجراؤها عبر الإنترنت بشكل آمن، مع الاحتفاظ بسجل شامل ودقيق لجميع أنشطة الطلاب (مثل تبديل علامات التبويب والتفاعلات) لضمان نزاهة الامتحانات وتوفير تقارير موثوقة للمراجعة.
